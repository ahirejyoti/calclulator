# HomeMatch

Static implementation of the HomeMatch discovery dashboard from Figma
(`zULrEkaJwkR2X0de5ABshS`, node `2:1956`). No build step or dependencies.

```
python3 -m http.server 8000   # then open http://localhost:8000
```

- `index.html` – markup
- `css/styles.css` – design tokens + layout (responsive down to phone width)
- `js/app.js` – save / compare toggles, map pin selection, search demo
- `assets/` – photos and icons exported from Figma (see `assets/README.md`)

All listings, prices and scores are illustrative.
